# Triage labels

The engineering skills refer to canonical triage roles. This repository currently configures only the role needed to hand a complete specification to an agent.

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | None | No label is configured for this role. |
| `needs-info` | None | No label is configured for this role. |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an agent. |
| `ready-for-human` | None | No label is configured for this role. |
| `wontfix` | None | No label is configured for this role. |

When a skill calls for a role without a configured label, do not substitute a different label.
