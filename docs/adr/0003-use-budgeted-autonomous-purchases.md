# Use budgeted autonomous purchases instead of per-payment human approval

A User authorizes a Task by assigning a Budget, after which the Agent may purchase Services without Human Approval while remaining inside that Budget. Requiring confirmation for every payment would undermine the core autonomous-commerce premise, while unlimited spending would make delegation unsafe. The hackathon MVP enforces the Budget in orchestration logic; stronger smart-account spending policies are a future enforcement mechanism rather than a requirement for the prototype.
